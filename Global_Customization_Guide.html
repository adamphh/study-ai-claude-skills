Cấu Hình Toàn Cục (Global Customization) cho AI Assistant

Làm thế nào để đội ngũ phát triển đồng bộ hóa các quy chuẩn lập trình, convention dự án và kích hoạt năng lực đặc thù (Skills) của AI trên tất cả các project mà không cần copy cấu hình lặp đi lặp lại.

Vấn Đề Thực Tế

Khó khăn khi làm việc đa dự án

✕ Phân mảnh cấu hình

Mỗi khi tạo dự án mới (P1115, P1062,...) hoặc clone repository mới, lập trình viên phải copy thủ công thư mục cấu hình .agents/ để AI hiểu context.

✕ Không nhất quán

Khi cập nhật quy chuẩn viết code (ví dụ: bổ sung cách viết plugin, observer, data patch), việc cập nhật thủ công từng thư mục .agents ở các dự án rất dễ gây thiếu sót.

Nguyên Lý Hoạt Động

Cơ chế Nạp Cấu Hình 2 Cấp Độ

AI Assistant hỗ trợ nạp các quy tắc và kỹ năng theo độ ưu tiên từ chung đến riêng:

➊ Phân vùng Toàn cục (Global)

Đặt tại /home/bss/.gemini/config/.
Được nạp cho mọi dự án mở trên máy. Thích hợp cho các quy chuẩn chung, convention code framework, git commit template và kỹ năng dùng chung (như sinh code Magento).

➋ Phân vùng Dự án (Local)

Đặt tại thư mục .agents/ của dự án.
Chỉ có hiệu lực cho dự án hiện hành. Thích hợp cho các cấu hình môi trường cụ thể, đường dẫn hoặc tài liệu hướng dẫn độc quyền của dự án đó.

Hướng Dẫn Cài Đặt

Các bước cấu hình Global

Sao chép các file cấu hình và thư mục kỹ năng vào đúng đường dẫn toàn cục:

  • Quy chuẩn & Nguyên tắc (AGENTS.md): Đặt tại /home/bss/.gemini/config/AGENTS.md
  • Thư mục Kỹ năng (Skills): Copy các thư mục skill tự định nghĩa vào trong /home/bss/.gemini/config/skills/. Ví dụ:
    /home/bss/.gemini/config/skills/magento-generate-dev/
Kinh Nghiệm Thực Tế

Cách phân bổ Rule tối ưu nhất

✦ Đưa vào Global config

- Các quy định giao tiếp (Tiếng Việt ngắn gọn, comment code tiếng Anh).
- Quy chuẩn Git Commit Message chung.
- Kỹ năng sinh code Magento 2 và WebPOS framework (vì dự án nào của team cũng dùng).

✦ Đưa vào Local config (.agents/)

- Các quy định đặc thù về phân quyền, thông tin phân nhánh của dự án cụ thể.
- API key cấu hình local hoặc các file hướng dẫn deploy dành riêng cho server kiểm thử của dự án đó.

Kết Quả Đạt Được

Lợi ích mang lại cho toàn Đội Ngũ

  • Tiết kiệm thời gian: Developer chỉ cần cấu hình môi trường máy trạm một lần duy nhất.
  • Đảm bảo tính nhất quán: Code sinh ra từ AI luôn tuân thủ đúng PSR-12, Magento Coding Standards dù dev đang làm ở bất kỳ repo nào.
  • Dễ dàng chia sẻ: Chỉ cần đóng gói thư mục config/ toàn cục gửi cho thành viên mới để họ bắt đầu làm việc hiệu quả ngay lập tức.
